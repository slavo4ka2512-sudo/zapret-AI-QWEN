# Zapret Discord & YouTube Unblocker (v1.9.8c)

## 📖 Описание

**zapret-discord-youtube** — это набор скриптов для обхода блокировок интернет-ресурсов на Windows с использованием утилиты `winws.exe` (Windows DPI bypass tool). Проект основан на технологии DPI-desync и предназначен для разблокировки:

- **Discord** (включая голосовые каналы)
- **YouTube** и Google Video
- **SoundCloud** и Spotify
- **Roblox**
- **Telegram**
- Других заблокированных ресурсов

---

## ⚙️ Как это работает

Проект использует технику **DPI-desync** (Deep Packet Inspection desynchronization), которая нарушает анализ трафика провайдером путём:

1. **Fake-пакеты** — отправка поддельных TLS/QUIC handshake пакетов
2. **MultiSplit** — разделение TCP-потока на части с перекрытием последовательностей (SEQ overlap)
3. **Host-based фильтрация** — применение правил только к определённым доменам
4. **IPSet фильтрация** — работа по спискам IP-адресов для массовых сервисов

### Ключевые компоненты

| Компонент | Описание |
|-----------|----------|
| `winws.exe` | Основной движок для перехвата и модификации пакетов (WinDivert-based) |
| `WinDivert64.sys` | Драйвер для перехвата сетевого трафика на уровне ядра |
| `.bin` файлы | Готовые шаблоны фейковых TLS/QUIC/STUN пакетов |
| `service.bat` | Менеджер службы для автозапуска и настройки |
| `general*.bat` | Предустановленные конфигурации с разными стратегиями обхода |

## 🚀 Быстрый старт

### Требования
- **ОС**: Windows 10/11 (x64)
- **Права**: Администратор (для установки драйвера WinDivert)
- **Архитектура**: Только x64

### Установка

1. **Распакуйте архив** в любую папку (желательно без пробелов в пути)
2. **Запустите от имени администратора**:
   ```cmd
   service.bat
   ```
3. В меню выберите:
   - **Option 1** — Установить службу (автозапуск при загрузке)
   - **Option 3** — Проверить статус

### Ручной запуск

Для одноразового запуска без установки службы:
```cmd
general.bat
```

Или выберите альтернативную стратегию:
```cmd
"general (ALT).bat"
"general (FAKE TLS AUTO).bat"
"general (SIMPLE FAKE).bat"
```

## 🎛️ Конфигурация

### Стратегии обхода

Проект включает **15 предустановленных конфигураций**:

| Файл | Стратегия | Описание |
|------|-----------|----------|
| `general.bat` | Standard | Базовая конфигурация для большинства случаев |
| `general (ALT).bat` — `ALT11` | Alternative | Различные комбинации параметров для проблемных провайдеров |
| `general (FAKE TLS AUTO)` | Fake TLS | Акцент на подделку TLS handshake |
| `general (SIMPLE FAKE)` | Simple Fake | Упрощённая конфигурация с минимальными правилами |

### Добавление своих доменов

1. Откройте `lists/list-general-user.txt`
2. Добавьте домены (по одному на строку):
   ```
   example.com
   subdomain.example.org
   ```
3. Перезапустите службу

### Исключение доменов

Для исключения доменов из обработки создайте `lists/list-exclude-user.txt`:
```
bank.ru
government.gov
```

- **Задержка**: Добавляет 1-5ms к RTT

## 🐛 Диагностика проблем

### Служба не запускается

1. Проверьте, что запущены от имени администратора
2. Убедитесь, что антивирус не блокирует `WinDivert64.sys`
3. Запустите диагностику (опция 10 в меню)

### Ресурсы не открываются

1. Попробуйте альтернативную конфигурацию (`general (ALT).bat`)
2. Проверьте актуальность списков (опция 7)
3. Запустите тесты (опция 11)

### Логи

Логи службы находятся в:
```
%SYSTEMROOT%\System32\config\systemprofile\AppData\Local\zapret\
```

Или просмотрите через меню (опция 3).
